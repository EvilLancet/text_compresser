# Text Compresser

Веб-сервис для сокращения текстов с помощью локальной LLM-модели Ollama. Приложение сохраняет смысл и важную информацию исходного текста, удаляя повторы и второстепенные формулировки.

## Возможности

- сокращение текста на шести уровнях — от минимального до максимального;
- сохранение языка, структуры и ключевых фактов исходного текста;
- отмена текущей операции;
- история сокращений для текущего браузера;
- копирование результата одним нажатием;
- последовательная очередь запросов к LLM;
- полностью локальная обработка через Ollama.

## Архитектура

Проект состоит из двух сервисов:

- **`site_service`** — веб-интерфейс, публичное HTTP API и SQLite-хранилище истории;
- **`llm_service`** — очередь задач и интеграция с Ollama.

Поток обработки:

```text
Браузер → site_service:8000 → llm_service:8001 → Ollama:11434
                 ↓
              SQLite
```

## Требования

- Docker и Docker Compose;
- Ollama, установленная на хост-системе;
- загруженная в Ollama модель, например `qwen3.5:4b`.

Загрузить модель:

```bash
ollama pull qwen3.5:4b
```

При использовании другой модели измените переменную `OLLAMA_MODEL` в `docker-compose.yml`.

## Запуск

1. Запустите Ollama и убедитесь, что она доступна по адресу `http://localhost:11434`.
2. Соберите и запустите сервисы:

   ```bash
   docker compose up --build -d
   ```

3. Откройте веб-интерфейс:

   <http://localhost:8000>

Проверить состояние веб-сервиса можно по адресу <http://localhost:8000/health>.

Остановить приложение:

```bash
docker compose down
```

История хранится в Docker volume `site_service_data` и сохраняется между перезапусками контейнеров.

## Конфигурация

Основные переменные задаются в `docker-compose.yml`:

| Переменная | Сервис | Значение по умолчанию | Назначение |
| --- | --- | --- | --- |
| `OLLAMA_URL` | `llm_service` | `http://host.docker.internal:11434` | Адрес Ollama |
| `OLLAMA_MODEL` | `llm_service` | `qwen3.5:4b` | Модель для обработки текста |
| `LLM_URL` | `site_service` | `http://llm_service:8001` | Адрес LLM-сервиса |
| `DATABASE_URL` | `site_service` | `sqlite:////data/sqlite3.db` | Строка подключения к SQLite |
| `MAX_TEXT_LENGTH` | `site_service` | `1000` в Compose | Максимальная длина текста на сервере |

`host.docker.internal` позволяет контейнеру обратиться к Ollama, запущенной на хосте. В Linux это обеспечивается настройкой `extra_hosts` в Compose-файле.

## Уровни сокращения

| Идентификатор | Название | Ориентировочный объём результата |
| --- | --- | --- |
| `minimal` | Минимальное сокращение | 85–90% |
| `light` | Лёгкое сокращение | 70–80% |
| `moderate` | Умеренное сокращение | 50–60% |
| `strong` | Сильное сокращение | 30–40% |
| `very_strong` | Очень сильное сокращение | 15–25% |
| `maximal` | Максимальное сокращение | 5–10% |

Проценты являются ориентиром для модели, а не строгим ограничением количества символов.

## HTTP API

Все основные маршруты доступны через `site_service` на порту `8000`.

### Проверка состояния

```http
GET /health
```

Ответ:

```json
{"status": "ok"}
```

### Получение уровней сокращения

```http
GET /levels
```

### Сокращение текста

```http
POST /process
Content-Type: application/json
```

Тело запроса:

```json
{
  "text": "Текст, который нужно сократить",
  "compression": "light"
}
```

Сервис устанавливает cookie `user_id`, связывающую запросы с историей конкретного браузера.

### Отмена обработки

```http
POST /stop
```

Операция отменяет текущий запрос пользователя или удаляет его из очереди.

### История

```http
GET    /history       # получить историю текущего пользователя
DELETE /history/{id}  # удалить одну запись
DELETE /historys      # очистить всю историю
```

## Локальный запуск без Docker

Для запуска сервисов напрямую установите зависимости из обоих файлов `requirements.txt`, затем запустите приложения в отдельных терминалах:

```bash
cd llm_service
uvicorn app.main:app --host 0.0.0.0 --port 8001
```

```bash
cd site_service
DATABASE_URL=sqlite:///sqlite3.db \
LLM_URL=http://localhost:8001 \
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Для `llm_service` при необходимости задайте `OLLAMA_URL` и `OLLAMA_MODEL` в окружении.
